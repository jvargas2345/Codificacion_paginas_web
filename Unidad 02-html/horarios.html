Como entregar una practica

  1. Traer los cambios de git pull
  2. La rama para la practica
  3. Trabajar y hacer commit atomicos
  4. Subir la rama con git push
  5. Revisar y fucionar el pull request
  6. Volver a la rama principal (main)
  7. Eliminar la rama de la practica con git branch -d "Nombre de la ramaS"
